# 🎮 Tic Tac Toe – Android Game

A modern and interactive **Tic Tac Toe** game for Android, built with **Kotlin** and **Jetpack Compose**.

The game supports playing against another player or challenging the phone with multiple difficulty levels.

---

## 📱 About The Project

Tic Tac Toe is a classic two-player game redesigned with a modern Android interface.

The project was built using modern Android development technologies and focuses on clean architecture, smooth animations, game logic, and an enjoyable user experience.

---

## ✨ Features

### 🎮 Game Modes

- 👥 Player vs Player
- 🤖 Player vs Phone

### 🧠 AI Difficulty

When playing against the phone, you can choose between:

- 🟢 Easy
- 🟡 Normal
- 🔴 Hard

The Hard difficulty uses the **Minimax algorithm** to make the phone play strategically.

### 🏆 Game System

- Detects winners automatically
- Detects draws
- Highlights the winning line
- Animated X and O symbols
- Winning cells animation
- Victory animation
- Confetti effect after winning
- Phone thinking indicator
- Prevents player interaction while the phone is thinking
- Replay the game
- Return to the main menu

### 📊 Score System

The game keeps track of:

- 👤 Player 1 / You score
- 👤 Player 2 / Phone score
- 🤝 Draw score

The score can be reset from the main menu.

### 🎨 UI & Visual Effects

- Modern dark interface
- Programmer-style visual design
- Electric blue and golden yellow color system
- Glowing X and O symbols
- Glowing buttons
- Animated game board
- Animated winning line
- Winning cell pulse effect
- Animated result panel
- Confetti celebration effect

---

## 🛠️ Technologies Used

- **Kotlin**
- **Jetpack Compose**
- **Android SDK**
- **MVVM Architecture**
- **StateFlow**
- **Navigation Compose**
- **Minimax Algorithm**
- **Material Design**
